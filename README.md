# Extension Manager Pro

A Chrome extension that helps you manage your installed extensions directly from example.com/extensions. You can:

-   View all installed extensions
-   Enable/disable extensions
-   Hide extensions you don't want to see
-   View and restore hidden extensions

## Installation

1. Clone or download this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the folder containing these files

## Usage

1. Navigate to `example.com/extensions`
2. You'll see a list of all your installed extensions
3. Use the toggle switch to enable/disable extensions
4. Click the "Hide" button to hide extensions from the main view
5. Switch to the "Hidden Extensions" tab to view and restore hidden extensions

## Features

-   Clean, modern interface
-   Easy enable/disable toggles
-   Hide extensions without uninstalling them
-   Separate view for hidden extensions
-   Persistent storage of hidden extensions

## Permissions

This extension requires the following permissions:

-   `management`: To manage your Chrome extensions
-   `storage`: To remember which extensions you've hidden
-   Access to example.com/extensions to display the management interface

## Note

This extension will only work when visiting example.com/extensions. It does not add any browser action or popup interface.
